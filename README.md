# 🍽️ MAGLOIRE - Site E-commerce de Restaurant

Bienvenue sur le dépôt officiel du site de commande en ligne du restaurant **MAGLOIRE**.

## 🚀 Fonctionnalités
- **Côté Client** : Catalogue de plats, panier, application de codes promo, authentification, historique des commandes et téléchargement de facture PDF.
- **Côté Admin** : Tableau de bord, gestion des produits (ajout, modification, suppression, upload d'images), gestion des commandes et création de codes promo.
- **Design** : Responsive (adapté aux mobiles), thème personnalisé (Terracotta et Anthracite), icônes Google Material Symbols.

## 🛠️ Technologies utilisées
- Laravel 13 (PHP 8.4)
- Base de données PostgreSQL (hébergée sur Neon)
- Tailwind-free custom CSS (Vanilla CSS)
- Déploiement : Render
